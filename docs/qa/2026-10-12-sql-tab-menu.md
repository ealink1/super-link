# SQL 标签批量关闭菜单

- SQL 工作区的查询、表数据、数据库目录、表设计及导入标签，点击或右键点击后先选中该标签，再打开关闭左边、右边、其他及所有标签的菜单。
- 与 Shell 共用菜单范围计算和边界禁用规则。过期菜单不会关闭剩余或新建标签，关闭按钮继续只处理所在标签。
- 批量关闭通过各文档原有的关闭流程执行，按显示顺序逐个处理，等待确认或查询草稿持久化完成。
- 未提交修改、正在执行的表设计/导入任务继续显示原有确认框。同一批次只出现一个确认框；取消确认或保存失败时停止剩余关闭。处理期间禁止发起另一批关闭。
- 查询保留草稿内容并记录关闭状态，避免下次启动重新打开；保存失败时恢复当前查询的编辑能力。
- 已关闭标签移除菜单、选中、关闭回调及共享悬浮提示引用。
