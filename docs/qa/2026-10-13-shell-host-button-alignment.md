# 主机管理按钮图标与文字对齐（2026-10-13）

## 原因与修复

`alignShellButtonText` 仍将按钮文字相对行框中心额外上移 2 点。此前这个补偿针对不完整的主字体行指标；修复中文回退行高后，它会使分组导航及页头按钮的文字比图标偏高。

带可见图标的按钮现在与图标共用垂直布局中心。纯文字按钮保留原有光学位置及调用方的 `textOffset`，避免改变笔记 H1–H4 和结果标签的现有位置。Fyne 的按钮点击、焦点、键盘、禁用及配色实现继续由原 renderer 处理。

## 验证

- 新增 `TestShellHostButtonIconAndTextPaintedAtSameHeight`，逐项覆盖“全部主机”“默认分组  3”“隐私模式”“新建主机”，检查普通、悬停、焦点和禁用状态下的真实图标/字形墨迹中心，允许小字号栅格差异不超过 1.5 像素。
- 既有刷新稳定性测试改为检查图标与文字行框中心相同、反复刷新没有积累偏移，移除固定要求旧的 `-2` 实现细节。
- 使用生产控件、主题和 SVG 图标的独立原生 OpenGL 窗口，在 1、1.5、2 倍缩放下各捕获修复前后状态；每张覆盖四种按钮及普通/悬停状态。旧对照仅通过 Go 源码覆盖恢复旧按钮对齐文件，保留中文行指标修复。检查确认修复后文字与图标同高，字形完整。
- 原生探针通过仅存在于 Go overlay 的诊断工厂使用未导出的生产按钮，没有向正式应用加入诊断入口。探针、截图及覆盖文件保存在本地忽略目录 `.cache/shell-buttons/`，内容不含真实主机或凭据。
- macOS 全量 Go 测试、静态检查、源码尺寸、架构与 Fyne 来源校验通过；相关 UI 竞态测试包含按钮像素对齐、笔记格式操作、中文裁切和监控对齐，全部通过。
- 使用 DejaVu 2.37 字体的源码覆盖复测也通过，包括按钮像素对齐、刷新稳定性和中文裁切；未将此本地复测视为 Linux 原生 GUI 验收。
