# SQL 输入补全验证（2026-10-15）

- 输入前缀自动提示 SQL 关键字、当前连接/数据库的表名和已引用表的字段。支持 `FROM` 等表名上下文、schema 限定名、表别名字段、中文名称和光标位于单词中间的替换。
- 方向键选择，Tab/回车接受，Esc 关闭；Ctrl+Space 手动提示。鼠标可点击候选。补全通过原生编辑操作替换局部文本，不修改系统剪贴板，不执行 SQL。
- Fyne 浮层单独管理焦点，候选框中的键盘代理把输入传回编辑器，避免弹出列表后无法继续输入。
- 发布前复现并修复补全框关闭时连带移除其上方弹窗的问题，恢复无关浮层的原有顺序和焦点；回归测试验证后台元数据回调不会关闭或抢走其他弹窗的焦点。
- 字符串、行/块注释、PostgreSQL dollar 字符串和命名参数中不提示。选中 SQL 时不提示，切换标签或 SQL/Shell/Note 工作区时关闭候选。
- 元数据在后台延迟加载、缓存；切换连接、数据库或 schema、执行 SQL、刷新对象和关闭标签会清理相应状态。校验连接修订号，取消旧加载，不显示后台元数据错误弹窗。
- 每次候选最多 60 条，表目录最多 5,000 项，字段缓存最多 20,000 个，每轮最多读取 8 张引用表、每表最多 2,000 个字段；元数据加载限时 10 秒。超过 256 KiB 的脚本停用补全以限制输入开销。
- 纯逻辑测试覆盖上下文、别名、限定名、Unicode 范围、引号、参数/注释排除和结果上限。软件 UI 测试覆盖自动提示、继续输入、键盘与行点击接受、元数据缓存、Esc 后不重开、选区、标签/工作区切换及加载中的切库和关闭取消。
- 全量 Go 测试、针对性竞态检查、`go vet`、源码大小、架构和 Fyne 完整性检查通过。
- 系统窗口采集工具报 ScreenCaptureKit 采集错误，未完成真实鼠标/键盘注入核验。改用独立原生 Fyne 窗口在事件循环中调用真实控件的输入方法，验证关键字、表、别名字段、方向键、Tab/回车及行点击回调和焦点恢复，并导出 OpenGL 绘制图检查候选框的位置和文字。探针仅存在于忽略目录的 Go overlay。
- 未使用浏览器，未向用户数据库发送测试 SQL；本机应用重新构建。
