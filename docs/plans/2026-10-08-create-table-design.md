# 新建表

数据库、Schema、表分组和连接右键菜单提供“新建表”。复用现有字段设计器，允许编辑字段名称、类型、主键、自增、非空、默认值和注释，支持新增、删除字段及 SQL 预览。

SQL 在 sqlworkbench 中生成，支持现有结构设计器的 MySQL、PostgreSQL 和 SQLite 方言及其兼容驱动。名称按字面量引用；字段类型及默认值经过校验。SQLite 不支持字段注释，界面提交时明确提示。自增必须为整数单列主键，SQLite 必须使用 INTEGER。

执行绑定被点击的连接、数据库、Schema 和连接版本，通过 Engine 的 structure 操作保留只读、结构保护与写入确认。后台作业使用 30 秒上下文；成功后刷新目标对象树，失败保留输入供修正。验证 SQL 方言和非法输入、SQLite 实际建表读写，以及 UI 目标绑定和确认后执行。
