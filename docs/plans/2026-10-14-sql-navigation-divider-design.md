# SQL 连接树左右分隔条

SQL 工作区的连接树与文档区域使用默认 Fyne HSplit。全局主题把命中宽度设为 1 像素，鼠标在线旁边 3 像素处拖动不能改变侧栏宽度。

沿用查询上下分隔条已验证的局部渲染方式，支持横向分栏：8 像素透明命中区域，中间为 1 像素灰色竖线，完整贯穿可用高度。正常和悬停都保留细线，颜色跟随亮暗主题。沿用 Fyne 的左右拖动、光标和最小尺寸约束，保持 0.18 初始比例及两侧已有内边距。仅修改 SQL 工作区侧栏，不扩大其他页面的分隔条或修改控件悬停样式。

回归验证连接树两侧附近像素的左右拖动、长 SQL 和结果区可见性，以及完整高度的细线在亮色、暗色、悬停与主题切换时保持可见。运行相关竞态、全量测试、静态检查和 macOS 原生验证；通过后构建、安装并重启最新应用。不使用浏览器，不提交或发布。
