# SuperLink 应用与驱动分仓发布

用户已确认沿用 GoNavi 的分仓发布方式。主仓库为 ealink1/super-link，驱动仓库为 ealink1/SuperLink-DriverAgents。

主 Release 仅上传 14 个应用包、发布说明、SHA256SUMS.txt 与签名清单及签名；平台构建元数据留在 Actions Artifact。驱动 Release 上传 131 个可选驱动、同一签名清单与签名及独立校验文件。

继续使用原有原生 Agent 和签名协议，不引入新的归档提取协议。应用从主仓库读取经 Ed25519 验证的完整清单，再从其中指向驱动仓库的 HTTPS 地址下载对应驱动，校验大小、哈希、修订与协议身份。离线 SQLite 保持随应用分发。

六个平台仍统一构建与验证。先生成、验证两个仓库的草稿，全部资产校验通过后才允许公开发布；公开时先发布驱动，再发布应用，避免公开应用指向未公开驱动。默认仍为草稿。已有发布与版本标签不修改。

跨仓库写入需要专用授权，普通 GITHUB_TOKEN 只用于主仓库。驱动授权仅交给发布步骤；普通构建不获取令牌及签名私钥。驱动仓库标签固定其仓库提交，发布正文记录应用源码 SHA。

验证覆盖仓库 URL 限制、真实签名与下载、两个上传清单的严格划分及独立校验文件、错误 URL 和额外文件拒绝，以及原生构建和六平台发布链路。不得使用浏览器测试。
