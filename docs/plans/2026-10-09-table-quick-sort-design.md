# 表数据正序与倒序

在表数据工具栏的筛选按钮后增加正序、倒序两个图标按钮，悬停显示中文说明。点击选择元数据中的有效字段，确认后按该字段进行数据库端排序，返回第一页并保留已应用的筛选与手动条件。

快捷排序替换当前排序字段，并同步已有多字段排序面板；需要组合排序仍可在筛选面板配置。加载中、已关闭及存在未提交编辑时阻止排序，避免丢失修改。通过现有后台表分页读取服务执行，事件回调不执行 I/O。

验证双方向 SQL ORDER BY、筛选保留、第一页重置、面板同步、无效字段及待提交编辑保护，以及原生构建和静态检查。不使用浏览器测试。

## 表头入口修正

按用户最新标注，移除工具栏快捷排序按钮和字段选择弹窗。每个数据字段表头右侧直接展示上、下箭头，点击对当前字段正序或倒序排序，当前方向高亮。行号和复选框列不展示箭头，未提供数据库排序回调的查询结果表不展示。表头文字预留箭头宽度，虚拟化复用绑定时使用当前列名，并检查过期网格，保留已有后台排序及未提交编辑保护。
