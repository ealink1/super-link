# 笔记正文富文本编辑

根据用户提供的富文本参考图，默认编辑区直接呈现标题、粗体、斜体、删除线、行内代码、代码块、引用与列表，隐藏对应的 Markdown 标记。正文使用比例字体、分级字号和段落间距，统一跟随应用明暗主题。

沿用本地 Markdown 存储和现有自动保存、导入、导出流程。原生 Fyne 编辑器以源字符位置映射展示文字与光标，复用 Entry 的输入、剪贴板和撤销历史；点击、拖动选择及方向键适配展示坐标，删除可见文字保留相邻格式标记。保留源码、预览和分屏入口。渲染不读取外部图片、不请求远程资源。

验证涵盖格式与源码分离、中文选区替换、插入、撤销、删除保留格式、源码切换、窄宽度换行、现有笔记生命周期与持久化测试，并生成明暗主题的软件渲染截图。原生构建后重启项目，不使用浏览器测试。

## 工具栏格式语义修正

H1–H4 对光标或选区覆盖的完整段落设置标题，替换已有段落类型；重复应用同一级别保持不变。行内格式基于当前样式开关，重复应用取消格式，保留格式化后的内容选区；组合粗体与斜体通过 Markdown 解析器渲染，避免重复分隔符泄露。回归测试通过真实工具栏点击覆盖按钮抢占焦点、反向选区、跨段落选区与重复格式操作。

## 全部工具栏动作

粗体、斜体、删除线和行内代码支持选区应用与取消；无序列表、有序列表和引用支持整段类型切换及取消，有序列表按选区段落连续编号。代码块支持从其他段落类型转换与再次点击还原，采用正文可见文字避免把已有行内 Markdown 标记展示为代码。代码区域使用背景区分，并禁用不适用的行内样式按钮。标题、列表、引用及行内格式状态随光标和选区同步高亮。

所有格式修改按一次用户动作撤销或重做，键盘与工具栏保持一致；文档历史限制为 64 条和 4 MiB，切换笔记清空历史。逐一点击全部 12 个格式按钮的测试覆盖反向选区、应用、状态高亮、重复应用或取消、单次撤销和重做，另覆盖列表连续编号与跨类型转换。

列表与引用的回车继续对应段落类型，有序列表递增编号；空条目回车退出列表或引用。对应行为与一次撤销一起回归验证。
