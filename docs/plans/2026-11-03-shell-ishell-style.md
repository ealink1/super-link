# Shell 工作区参考 iShell Pro 样式

用户提供 iShell Pro 终端截图并要求打开软件参考 UI，随后确认调整范围仅为
Shell 工作区。此视觉方向用于 Shell 的样式更新；保留 SuperLink 品牌、现有
功能、纯 Rust/GPUI 实现与共用工作区。

## 参考与设计

通过原生应用 `cc.ishell.pro` 查看现有综合及 CPU 页面，回到原综合页面；
未使用浏览器、未执行终端输入或停止进程。只观察当前窗口，没有读取其实现代码。
图标复用项目已审查资产，不复制 iShell Pro 的品牌图标或代码。

浅色底为 #EFF1F5，卡片为 #EAECF0，导航轨道为 #E6E8EB，文字为 #4D4F69，
边框为 #D3D5D8。紫色用于选中态；青、粉、橙、绿用于 CPU、内存、磁盘、网络。
该配色限定在 ShellWorkspace 内解析，不修改 SQL / Note 的全局主题。

- 监控侧栏宽度改为工作区 32%，保持 320–420px 上下限。
- 主机身份使用紧凑横向卡，用户名/地址徽标及运行时间各自对齐。
- 概览采用中性边框、彩色数值、双列指标卡与水平网络上下行速率。
- CPU 详情采用 3×2 指标卡和每行四个紧凑核心块；保持最小宽度及独立行高。
  本地探针未采集的用户态/内核态/IO 等待显示 N/A，不伪装为测得的 0%。
- 历史曲线增加轻网格、青色曲线/淡填充及实际时间标签，数据仍受原 60 秒预算限制。
- 分区及网络接口改为全宽紧凑条目；底部现有工具栏调整字号/高度及重连图标。

本轮不新增批执行、录制、分屏等参考应用功能，也不声称整页逐像素复制。
深色使用现有主题基础与监控色系，未以参考应用的深色页面进行视觉验收。

## 验证

独立临时工作区及本机 8 核实时数据原生验证综合、CPU 网格及 320px 窄侧栏。
已并排比较两版综合监控的截图并调整字号、卡片与曲线密度；截图视口并不完全
一致，比较时归一化侧栏宽度，因此不能视为整页逐像素验收。

77 项 UI 测试、严格 Clippy、格式、架构、资产来源、空白检查与 macOS 构建通过。
