# 连接右键新建库

连接节点右键菜单在新建查询后添加新建库。点击后输入库名，确认创建，通过现有 Engine 执行 CREATE DATABASE。对库名按数据库方言引用，拒绝空名称、控制字符及超长名称。

不支持 CREATE DATABASE 的数据源禁用入口。只读连接保留可点击菜单，点击解释只读保护并提供编辑连接入口，不自动修改只读设置。后台任务具有 30 秒超时并携带连接版本，错误在 UI 显示，成功后刷新原连接的数据库列表。菜单回调固定使用右键点击的连接，不依赖之后变化的选中项。

验证包含库名引用及非法输入测试、菜单与只读策略测试、UI 回归、静态检查和原生构建。未连接真实数据库执行建库，也不使用浏览器测试。

## 创建弹窗与执行确认修复

创建弹窗使用纵向字段布局：数据库名称、字符集、排序规则及底部取消/确定按钮。MySQL 兼容数据源异步读取 SHOW COLLATION，并按字符集过滤排序规则，默认不指定选项，使用服务器默认值。其他数据源禁用字符集字段。

执行服务返回 ConfirmationRequired 时显示目标连接和完整建库语句，用户确认后使用返回的指纹重试同一请求，保留现有写入保护。普通执行错误不自动重试。字符集和排序规则只接受字母、数字及下划线，库名按方言引用。
