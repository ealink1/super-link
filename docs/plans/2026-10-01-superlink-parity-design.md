# SuperLink 功能与界面一比一对齐实施设计

用户于 2026-10-01 明确要求功能和界面风格均对齐 SuperLink。本要求取代此前仅基础 Alpha 的交付范围，JVM 管理连接器继续排除。

## 目标和依据

以本机 SuperLink 1.0.0 的 28 张原生截图、页面操作记录及本地上游样式为依据。
保留独立 Go + Fyne 实现；页面名称、布局、颜色、尺寸、图标、状态和核心操作路径均作为验收项。
原生字体渲染与平台窗口装饰的差异单独记录，不以此忽略应用内容中的可修正差距。

## 实施顺序

1. 设计令牌与公共控件：移植 SuperLink 颜色、字号、紧凑间距、圆角；使用上游已有图标资产，保留出处。
2. 主窗口：顶部全局操作、固定初始宽度的侧栏、层级对象树、查询及其他工作标签；上下文和环境状态贯穿页面。
3. 查询与结果：单行上下文和图标工具栏、编辑器、日志 / 参数 / 结果分区、结果网格、字段与 DDL 视图。
4. 表工作台：双击对象直达数据页，读取元数据、条件构建、排序与服务端分页；数据 / 结构 / DDL 页互相切换。
5. 编辑与结构：主键定位、变更集、SQL 预览、受保护提交与回滚；字段、索引、外键、触发器按驱动能力开放。
6. 文件与任务：完整导入导出、比较同步、诊断、设置、驱动和更新；每个业务域单独实现，不以无行为按钮替代完成项。

## 分层与生命周期

界面只承接用户输入和呈现状态，SQL 方言、分页与数据变更生成放入独立领域包。
元数据以 runtime 可选接口读取，应用服务负责策略、会话及取消；不扩大所有协议的必选 Client 接口。
对象树惰性加载；每个请求绑定节点和连接修订，过期响应不能更新当前页面。关闭页面取消并等待任务释放。
敏感凭据和业务数据保持既有保护；使用独立测试工作区和自建演示数据进行写入验证。

## 验证

- 领域测试覆盖标识符引用、分页、排序、筛选和行定位边界。
- Fyne 控件交互覆盖树展开、对象双击、上下文切换、标签关闭、取消与失败状态。
- 自建 SQLite / MySQL / PostgreSQL 验证真实元数据、分页及编辑；未具备环境的类型明确记录。
- 使用电脑控制捕获原生实现，在相同窗口尺寸、主题和状态下与参考同时对照，记录在根目录 design-qa.md。
- 不使用浏览器测试；不提交或推送，除非用户明确要求。

当前实施状态在功能对照文档中持续记录，未完成或视觉尚未通过时不标为一比一完成。
