# SuperLink 数据源选择页美化

依据用户提供的 HTML/CSS 参考，重做新建连接的第一步，保持原生 Fyne 实现。

- 浅灰底色、独立圆角白色面板、蓝色活动步骤和分类选中态。
- 顶栏显示 SuperLink、三步流程及叉号关闭按钮。
- 左侧搜索和分类计数；右侧紧凑数据源卡片、分类标签、结果数量和实际应用版本。
- 保留真实数据库图标；分类与总数使用现有目录，不复制示例中的不一致分类或 v1.0。
- 卡片按可用宽度排列，窄窗口收为单列；兼顾深色主题、悬停和键盘选择。
- 搜索、分类、进入配置表单与关闭行为保持；本页无 I/O。
- 通过 Fyne 软件画布检查两种主题及大小窗口，不使用浏览器测试。

## 验证结果

- UI 全量测试、相关竞态测试、go vet、架构和文件体积检查通过。
- 1180×780 与 760×620 的日间 / 夜间 Fyne 软件画布已检查，覆盖搜索、分类组合筛选、空结果、选择和网格高度。
- macOS arm64 编译通过，本地 SuperLink.app 与 ZIP 已更新。未使用浏览器；未进行 Windows / Linux 原生验收。
