# macOS 主窗口隐藏与后台运行

用户要求关闭主窗口时隐藏窗口并继续后台运行，点击 Dock 恢复，菜单退出和 ⌘Q 才真正退出。

macOS 的窗口关闭拦截仅隐藏现有窗口，不取消工作队列、不关闭 SSH/数据库会话，也不重建标签或笔记。Dock 重开通过 AppKit 应用 delegate 转入 Fyne UI 队列，显示并聚焦原窗口。其他平台继续现有关闭退出行为。

使用原生 delegate 包装器处理重开与应用终止，其他 AppKit 事件转发到 GLFW 原 delegate。真正关闭时恢复原 delegate 并释放 cgo handle；无需修改 vendored Fyne 或 GLFW。

原生应用退出请求与文件菜单退出复用原有保存、取消任务、释放服务流程。隐藏状态退出先显示窗口，确保未保存修改确认可见。应用内更新仍使用同一 shutdown 流程。关闭按钮在退出过程中不再隐藏窗口。

验证包含隐藏期间后台任务/终端状态保留、恢复窗口身份、隐藏退出的最终笔记保存及会话释放、未保存修改确认。macOS 原生探针检查真实关闭事件、Dock delegate 重开及 ⌘Q 原生退出行为；不使用浏览器。
