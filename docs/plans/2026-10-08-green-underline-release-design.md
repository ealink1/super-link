# SuperLink v0.1.5 绿色下划线与公开更新

用户要求将 macOS 标题栏的 SQL / Shell / Note 选中背景改为绿色下划线，并随后
明确要求发布新版本，以便从本机 0.1.4 测试应用内更新。

## 界面

保留 AppKit 分段控件的鼠标、键盘和辅助功能行为，自绘普通文字、浅色底及选中项
底部的 3px 绿色下划线。下划线跟随模式切换，亮暗主题使用现有主题主色。
键盘焦点保留轮廓提示。不改动 SQL / Shell / Note 的工作区状态与切换逻辑。

macOS 原生构建、工作区切换及主题测试、架构检查已通过。未使用浏览器测试。
下划线的实际安装版视觉效果由用户通过本次更新验收。

## 发布

版本为 `v0.1.5`，保留已有版本标签及草稿。先由现有工作流完成六个平台原生
构建、安装包验证、签名和上传校验；确认两仓发布内容后先公开驱动、再公开应用。
采用现有更新签名公钥，并独立验证签名清单、平台资产和匿名稳定更新入口。

本机已安装的 0.1.4 保持原版本供用户手动测试升级；不替用户启动应用内安装。
云端结果、公开发布地址与稳定更新验证结果在发布完成后记录。

## 执行结果

提交 `42c36219189d64149eb3124bd72ce7bed22af78f` 与标签 `v0.1.5` 已推送。
主分支、标签 CI 及六平台 Release 工作流全部通过。独立校验两仓的 152 个资产
digest 和 137 条签名更新记录后，已按驱动 → 应用的顺序公开，均为 latest 稳定版。

匿名更新请求确认 0.1.4 可发现 0.1.5，强制 API 403 后真实备用入口也可发现该版本。
公开 Mac ARM64 更新 ZIP 的下载、长度、哈希、解压、版本及应用签名校验通过。
未替用户执行应用内安装，详细证据见发布文档第 13 节。
