# Shell 与 Fyne 实现的差距修复

用户要求继续修复 Rust Shell 与 Fyne 的功能差距。依据 `9816f626^` 中最后保留的
Fyne Shell 源码、归档的主机编辑器/会话/标签菜单验收记录，以及当前原生界面。
保持纯 Rust、共用本地工作区，不安装或替换 `/Applications/SuperLink.app`。

## 实施范围

- SSH 凭据同时读取 Fyne 的大写字段与早期 Rust 小写字段，写入保持两版可读；
  未记住凭据只放内存。保存冲突先检查，修改主机地址/端口清除旧指纹，确认指纹
  仅更新元数据。损坏凭据明确报错，不假装密码为空。
- 主机卡片和列表提供编辑、测试、复制密码、删除菜单；按名称/地址/用户名/
  分组/备注/标签/系统搜索，分组与真实标签可组合筛选。记住列表/隐私偏好。
  主机表单提供密码/密钥认证、原生私钥选择、系统、记住凭据及仅认证连接测试。
  测试遇到未知指纹需明确确认，地址改变或表单关闭后不复用旧确认。
- 连接过程展示来自实际 SSH 传输的四阶段状态，支持取消；失败可手动重连。
  终端保留在左侧，SFTP/监控在可收起的右侧面板，底栏提供状态、重连与字号。
  欢迎页、主机管理、设置与会话切换保留会话。
- 会话标签支持左右/其他/全部关闭及快捷切换，按稳定标识处理关闭范围，
  关闭全部恢复欢迎页。关闭继续经过既有资源释放路径。
- 终端恢复应用方向键、组合导航键、功能键、设备状态响应、括号粘贴及
  粗体/斜体/下划线/反色。翻看历史时新输出保留滚动位置。
- SFTP 增加名称搜索、隐藏文件筛选、目录优先排序、大小/时间列与实时进度刷新。
  文件操作绑定已加载目录，文件选择器返回后校验会话代次。监控采样与传输分开，
  避免互相抢占状态；过期定时器不得重复建立采样循环。

## 验证及边界

使用临时目录、PTY 和本机隔离 SSH/SFTP 服务验证数据、认证、取消和资源释放；
使用原生开发版检查布局、主机菜单、本地终端、监控及标签操作，不连接业务主机。
不使用浏览器、不提交或推送。详细结果补充到 `design-qa.md`。

这次修复对照实际 Fyne 已实现能力；归档路线图中的分屏、批量命令、录制回放、
Telnet/串口/远程桌面等目标仍未完成，不能称为整个路线图已对齐。

## 第二轮：按原版实际运行界面对照

截图反馈后重新运行已安装的 Fyne 0.1.30，使用独立临时工作区和本地
多主机密钥 SSH/SFTP 服务，不连接业务主机。原版截图保存在
`.cache/shell-parity-v2/01-fyne-local.png`、`02-fyne-connected.png`、
`03-fyne-failed.png`；对应 Rust 截图为 `04-rust-connected.png`、
`05-rust-failed.png`（均为本地验收产物，不纳入发布包）。

- 终端改为跟随应用主题，恢复 8px 内边距、圆角状态标签及原版底栏顺序，
  字号范围 10–24。浅色 ANSI 文字调整亮度以保持可读性。
- Shell 默认进入主机管理；进入主机管理隐藏终端标签但保留会话，终端导航
  返回已有会话，不额外创建本地进程。
- 恢复 512×400 连接模态窗口、四阶段状态和有限日志。失败保留窗口，
  可以重试或关闭，连接中关闭会取消。真正变化的指纹仍拒绝连接。
- 发现 Go 默认优先 ECDSA、russh 默认优先 Ed25519，导致同一个多密钥服务
  的旧指纹被误报变化。恢复原版优先顺序，并在保存指纹不匹配时，在原始
  超时/取消预算内尝试其他强密钥类型；只有原保存指纹完全匹配才认证。
  未知密钥不自动信任，不覆盖已有指纹。隔离测试覆盖新旧两种指纹和拒绝
  未知/变化密钥且不发送认证凭据。
- SSH 成功自动打开右侧监控；宽度为 29%（320–420px），恢复紧凑的
  综合/CPU/GPU/MEM/DISK/NET 导航、四个指标卡、历史曲线、文件统计入口、
  折叠恢复把手，以及右键刷新/暂停/1、3、5、10 秒间隔。

验收仍区分源码恢复、原生观察和真实服务器联调：未连接用户业务服务器，
未全量覆盖所有窄窗口、复杂全屏终端程序及全部路线图功能。
