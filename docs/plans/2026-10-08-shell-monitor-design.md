# Shell 实时监控面板

通过电脑控制查看已安装的 iShell Pro 参考界面；SuperLink 使用原生 Fyne 实现，不引入网页运行时。

## 观察与实现

- 综合：主机/IP、系统、运行时间、CPU/内存/磁盘/网络卡片，CPU 趋势、分区、网卡。IP 可复制，卡片可切换详情。
- CPU：总占用、核心数、1/5/15 分钟负载、温度、User/Sys/IO Wait、最近 60 秒曲线、各核心和进程排行。
- GPU：NVIDIA 利用率、显存、温度；设备或工具缺失时说明原因，并提供安装命令复制。
- MEM：可用/已用/缓存/缓冲/空闲/Swap、进程内存排行。
- DISK：各分区用量、设备 IOPS；指定目录、大小阈值、Top 数量的大文件扫描，支持取消、复制路径、打开 SFTP 所在目录。
- NET：连接数、TCP/UDP/TIME_WAIT、文件句柄、流量曲线、监听端口（复制地址）、网卡 IP/吞吐/累计流量。
- 底部：当前 SFTP 目录的 PATH/DIR/FILE/TOTAL 统计；此统计不是递归目录大小。

## 采样与生命周期

SSH 连接成功默认显示监控。自动刷新默认 3 秒，可选择 1/3/5/10 秒或暂停。隐藏面板、切换终端或离开 Shell 后暂停自动采样。CPU 和吞吐由计数器差值计算，首次采样不伪造百分比。曲线按最近 60 秒保留，最多 61 点。

通过独立 SSH channel 执行固定只读探针。基础指标仍要求 Linux；可选 GPU、温度、ip/ss 等工具缺失不影响基础采样。单次输出上限 256 KiB；核心、网卡、分区、进程及监听端口均设上限。I/O 在任务线程执行；绘制、回调及状态在 Fyne goroutine 更新。进程仅收集名称，不读取包含潜在凭据的命令行。

停止进程前弹出确认，校验 PID 和内核 start ticks 后发送 SIGTERM，避免 PID 复用。大文件扫描由用户触发，服务端 timeout 25 秒、客户端 30 秒；可取消，不删除文件。扫描依赖 Linux GNU find/sort/head/timeout，无权限目录会跳过。

## 验证边界

解析、速率、计数器重置、输出上限、命令参数与 shell 语法、六个页签、历史容量、窄窗口渲染和原生构建均做验证。参考主机仅用于观察，不执行终止进程、扫描或安装驱动操作；真实生产 SSH/GPU 操作仍需实际环境验证。
