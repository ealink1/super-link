# 数据库右键执行 SQL 文件

数据库节点右键新增执行 SQL 文件。使用原生文件选择器筛选 SQL 文件，通过现有 queryfile 的有界、可取消读取加载。捕获右键点击的连接、版本和数据库，不依赖之后改变的选中项。

后台读取后分类脚本的读写性质；只读连接拒绝写入文件。载入命名查询页供查看，显示文件、连接和数据库确认后执行整个文件快照，复用查询执行、参数校验、服务端写入确认、日志及结果展示。取消确认保留查询页便于检查，不执行 SQL。

验证确认前不执行、确认后使用原连接和数据库执行只读文件、只读写入保护、静态检查与原生构建。不对用户真实数据库执行测试，不使用浏览器。

## 大文件无总大小限制

执行 SQL 文件不设总大小限制。超过编辑器文档预算的文件使用流式分句、预检摘要和语句计数，不载入编辑器；内存随单条语句大小增长，而不是整份文件。扫描器处理引号、转义、注释、PostgreSQL dollar quote，文件结束时拒绝不完整语句。

预检确认只读保护、连接版本和脚本策略，执行前重验文件摘要。写入文件以整文件摘要绑定现有执行授权，整个文件持有一个会话租约，保留 SET/USE 状态；执行后丢弃会话。逐条执行，保留既有查询超时，支持停止、显示完成/总语句和读取字节；失败报告已完成语句，已执行内容不会自动回滚。审核记录仅保存 EXECUTE SQL FILE，不记录文件内容。

测试超过 1 MiB 的单条语句和大文件执行、字符串/注释分句、确认保护、修改文件拒绝、只读和取消后的会话释放。已只读解析用户约 296 MiB 的 SQL 文件，成功分出 410756 条语句，未向真实数据库执行。

## 执行详细进度

执行前的摘要核对显示读取字节、已核对语句数和阶段进度；读取回调覆盖单条大语句扫描。执行阶段显示当前语句序号、已完成/总语句、已读取大小、执行速度与耗时。连接数据库单独展示阶段。界面每秒刷新耗时，回调节流到 100ms，停止或完成后释放计时器，所有界面更新通过 Fyne 调度。

## 预检反馈与批量导入优化

选择文件后立即展示可取消的预检进度，完成后展示执行确认。MySQL/MariaDB 对相同表及列、连续的字面值 INSERT VALUES 合并成多行 INSERT，每批最多 128 条且目标不超过 512 KiB；超大的单条语句仍允许执行。识别 SuperLink 导出的十六进制二进制及 CONVERT(X'...' USING utf8mb4) 文本字面值。不合并表达式、冲突子句、其他数据库或其他语句；保持顺序和会话。失败报告批次序号范围，不自动重试，批次在非事务表上可能部分写入。计数仍按原文件语句统计，内存只保留一个有限批次或一条大语句。

只读规划实际 296 MiB 文件：410756 条语句合并为 3256 次数据库请求，减少约 99.2% 往返。仅验证扫描与批量计划，未执行真实数据库写入；网络、索引、触发器和服务端写入开销仍影响实际速度。

## 单框统计、摘要核对及确认执行

用户指定流程取代此前多次确认流程：同一个对话框先流式统计语句并判断写入，再单独计算 SHA-256 核对第一次统计所得摘要。核对只读取字节，不再分句和分类。两阶段完成后显示连接、数据库、条数、大小及写入说明，启用“确认执行”。

点击确认后消费一次性的 PreparedSQLFile，直接执行已检查文件，不再全文件预检，也不另弹写入确认框。所有大小文件统一使用此流程。准备阶段关闭文件，确认时重新打开并检查文件身份、大小和修改时间；连接后再次核对这些元信息，执行过程中持续检查文件元信息和连接版本。修改或替换文件、连接配置变更以及取消都会使准备结果失效。准备对象不缓存 SQL 内容或持有数据库会话。

统计、核对、等待确认、执行进度和最终结果均保留在同一对话框；支持停止和关闭，完成后刷新数据库导航。完成阶段不接收过期进度回调。测试确认前无写入、单次确认且不重复扫描、变更/取消拒绝，以及读写脚本在同一对话框执行。
