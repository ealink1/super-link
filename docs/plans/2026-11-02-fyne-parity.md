# Fyne → Rust 完整对齐验收

基准为本仓库 `main` 的 Fyne 实现及 2026-10-01 完整对齐设计。目标程序仍为
Rust + GPUI；Go driver-agent 保留。JVM 排除。模块存在不代表用户流程已完成。

## 实施与验收顺序

1. 执行与生命周期：只读/保护策略、参数绑定、选中执行、多语句、停止、超时、
   标签/连接/表请求身份隔离、退出释放。
2. SQL 工作区：连接/数据库/Schema 选择、草稿和结果按标签隔离、拖动分隔、
   行列浏览与复制、表编辑及变更预览、结构与真实 DDL、完整对象目录。
3. Note：标题/正文/标签编辑、预览与分屏、格式工具、撤销重做、分组、
   Markdown 导入导出、自动保存、回收站与修订冲突。
4. Shell：后台保活的多会话标签、窗口尺寸联动、文本选择复制、主机编辑、
   SFTP、监控、设置、指纹确认与重连。
5. 文件与桌面：导入导出任务与取消、驱动管理、设置、AI、更新入口、
   macOS 隐藏/恢复与退出、开发构建与发布路径。
6. 布局与优化：与原版相同的窗口/主题/状态下核对尺寸、密度、选中样式、
   菜单、字体、空/错/忙状态；恢复有界缓存、异步 I/O 与任务清理目的。

## 验证规则

- 每项分别记录底层实现、UI 接通、自动验证、原生视觉验收，不能相互替代。
- 使用独立测试工作区与自建 SQLite 数据；远程数据库/SSH 实机未测时明确列出。
- Rust fmt/clippy/test/build、受影响 Go 检查；不调用浏览器。
- 修改验证后构建并重启仓库内开发进程，不替换或终止 `/Applications` 安装版。
- 不提交、不推送。

## 初始核查

基线 Rust 测试已启动。已确认缺口：查询停止与参数、受保护写入、异步过期回填、
固定编辑区与笔记侧栏、只读笔记、多终端/SFTP/监控未贯通，以及旧构建脚本路径。
后续以实际测试和代码更新本清单；完整视觉验收通过前不声称一比一完成。

  长段换行滚动、Markdown 预览、单行中文插入、本地终端尺寸与多标签保活、深色设置页。
