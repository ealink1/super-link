# 字段设计器功能对齐

用户指出此前只有只读展示。此次以 GoNavi 字段页为验收对象，直接实现可编辑的字段草稿。

- 字段网格：名称、可选/可输入的类型、无符号、主键、自增、非空、默认值、注释。
- 多选、追加/选中后插入、删除、上移/下移和拖动排序；所有修改先留在内存草稿。
- 字段复制粘贴使用有版本的结构 JSON，并限制数量/字节；粘贴重名自动生成新名字。
- 复制到同库已有表或新表，独立预览，按目标表结构检查冲突。
- 表备注、保存、刷新（有草稿时明确保留/放弃），关闭有变更标签不得静默丢弃。
- 后台读取完整字段属性；MySQL 使用一条 ALTER TABLE 提交字段、顺序、主键、自增和表备注。
- 保存前重新读取结构，拒绝并发结构变化与配置修订变化；执行与预览由同一个纯函数生成。
- 非 MySQL 方言按真实能力处理，不能执行的改动必须在预览前明确拒绝，不显示成功。
- 验证采用纯函数回归、SQLite 隔离数据库真实保存及原生操作；不测试业务写入、不使用浏览器。

## 验证结果与边界

- SQL 47、应用 60、UI 82 项测试；严格 Clippy、原生构建、格式与架构检查。
- SQLite 真实改名/新增、保留数据、外部结构冲突、只读阻止保存、后续 DDL 失败事务回滚。
- 官方临时 MySQL 8.4.13（独立 datadir、回环地址）实测属性/顺序/备注、主键切换、自增开关、
  字符集/默认值保留、反斜杠/引号、复制新表、非法转换原子失败以及复合主键的顺序保留。
  可重复的验收入口为 superlink-app 的 verify_field_designer_mysql 示例，强制核对服务器 datadir
  属于指定 QA 根目录，不允许对任意数据库运行。
- 原生隔离工作区验证类型菜单、字段输入/默认值、复制粘贴重名、复制新表、草稿关闭保护、
  放弃草稿；MySQL 原生拖动 v4 到 v0 前并取消 v1 非空后保存、目录回读一致。
- 原生截图：.cache/sql-gonavi-qa/field-designer-mysql.png。
- SQLite/PostgreSQL 不支持的字段变更仍明确拒绝，不能将 MySQL 能力笼统用于所有数据源。
  生成列、ON UPDATE 与复杂 enum/set 定义继续要求显式 DDL；外键/触发器仍为查看模式，
  索引沿用已有编辑流程，不声称这些编辑器与 GoNavi 全面对齐。PostgreSQL 本轮未真实服务联调。
