# 批量删除选中的表

在“所有表”列表顶部刷新按钮右侧新增删除图标。未选中表、只读或结构保护开启时禁用。点击后固定当前选择，按列表显示顺序列出表名和连接信息，确认删除结构及全部数据。

应用层将单次确认绑定到完整表列表、连接版本和数据库。逐表执行 DROP TABLE，避免依赖驱动多语句配置，仍通过 Execute 校验实时策略和连接版本。最多 1000 张表，SQL 总量最多 1 MiB。

后台任务使用可取消上下文，关闭列表页或应用时取消；显示已完成数量。遇到失败停止，不重试结果不确定的写入。返回已完成表列表，移除对应选择、关闭对应表数据页，并对导航和各表列表仅刷新一次。确认取消保持选择。

验证确认前零写入、变更选择使确认失效、单次确认逐表执行、部分失败停止、只读/结构保护，以及图标启用状态、表名预览和取消恢复。运行相关测试、静态检查及原生构建后重启，不使用浏览器。
