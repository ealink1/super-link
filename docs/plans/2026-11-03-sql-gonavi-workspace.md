# SQL 工作区参考 GoNavi

范围：用户红框内的 SQL 工作区。保持 SuperLink 品牌、原生 Rust/GPUI 和共享本地工作区，不改动已安装应用。

## 交互与布局
- 连接树常驻；树自身滚动，页脚固定；紧凑行高与当前表绿色选中。
- 表标签按打开顺序排列，至多 16 个；各自保留数据、筛选、排序、分页、选中行、暂存变更和列宽。
- 查询入口与表标签并列。加载和写入期间阻止切换；关闭有暂存变更的标签必须先提交或撤销。
- 紧凑对象工具栏：刷新、展开筛选/导入、增删行、导出。危险表操作只生成 SQL，不直接执行。
- 网格固定字段宽度、可拖动调整列宽、字段类型/主键、行选择、单元格选中、完整值查看和复制、横纵滚动。
- 底部数据/结构/DDL、JSON 视图、首末页/前后页、50/100/200 行分页。
- 连接配置修订变化使所有关联表标签失效，禁止旧连接状态执行。

## 验证
Rust 单元测试与严格 clippy；原生构建；隔离 SQLite 数据工作区验证多标签、滚动、列宽、排序、分页与变更保护。不使用浏览器，不查询或修改业务数据。

## 边界
本次复用现有数据库对象能力，不把 GoNavi 的 AI、用户管理或 ER 图按钮作为无实现的装饰。查询编辑器保留独立查询标签和参数、日志、字段、DDL 功能。

## 表节点二次对照

GoNavi 表展开后为“列 / 索引 / 外键 / 触发器”四个叶节点，点击后打开右侧对应结构页。
本次替换直接铺开字段与“编辑结构”链接的旧树形行为。结构浏览不自动扫描表数据；切回
“数据”时才请求数据页和计数。每个数据库下提供已存查询入口，按连接和数据库过滤。
表行数优先显示已读取的无筛选计数；MySQL 目录统计以 ≈ 标明估计值，未知不显示。
触发器目录目前覆盖 SQLite、MySQL 与 PostgreSQL 方言家族；其余明确提示尚未支持。
外键与触发器目前提供只读浏览；其修改能力尚未对齐 GoNavi，不宣称完全功能一致。
