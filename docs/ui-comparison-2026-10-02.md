# SuperLink 与 SuperLink 原生界面对比

> 名称与命令已于 2026-10-03 统一为 SuperLink；历史截图、产物哈希和验收结论仍对应记录当日版本，本次更名验证见 [完整更名记录](superlink-namespace-2026-10-03.md)。

日期：2026-10-02。结论：**当前版本没有达到功能、操作路径和界面风格的一比一复刻。**
本轮已实际打开两个 macOS 应用，以当前原生页面重新核对，不能把此前的软件截图、
图标文件哈希或单测通过当作原生视觉验收通过。

## 1. 对比环境与证据

| 操作方式 | 电脑控制原生应用；未使用浏览器 |
| 本轮证据 | 17 张完整窗口 JPEG，另隔离 1 张 Stage Manager 缩略图，不作为验收证据 |
| 证据目录 | `.cache/ui-compare-2026-10-02/`，原始截图字节、可用 AX 文本及 `manifest.json` |

截图均来自本次操作，保存后重新打开检查；早期扩展名为 PNG 的文件实际是 JPEG，
已仅更正扩展名，未重绘、裁剪或加工画面。截图包含本机连接 / 对象上下文，
仅留在忽略的本地缓存中，不纳入 Git 或公开分享。

和 Fyne 已选本地 SQLite。因此下文比较页面结构、公共控件和操作路径，
没有计算像素误差、相似度百分比，也没有给出完整产品通过分数。

## 2. 可保留的实现与主要问题

可以保留绿色主色、顶部主要动作名称、接近原版的侧栏宽度，以及连接 / 库 / 表的
树形层级。Fyne 本地 SQLite 的对象展开、表数据、字段和 DDL 在本轮实际能够打开。
这些已有能力为后续对齐提供基础，但页面的结构和控件状态仍有明显差距。

| 优先级 | 本轮发现 | 用户影响 / 验收标准 | 证据 |
| --- | --- | --- | --- |
| 高 | Fyne 使用独立原生标题栏，再放全局工具栏；原版工具栏与标题栏结合。字体、字重、标签宽度及间距不同 | 同一窗口下工作区整体下移；先固定窗口、工具栏和标签的尺寸再对齐其他页 | 02 / 08、06 / 14 |
| 高 | 欢迎页仍是标题加说明，缺少原版操作区和五块工作台卡片 | 最近连接、已存查询、SQL 文件和置顶表的入口及信息结构不一致 | 02 / 08 |
| 高 | 数据源选择器卡片顺序、弹窗宽度、最近使用、收藏、SSL 标签和步骤状态未对齐 | 用户选择类型的路径和视觉定位不同 | 03 / 09 |
| 高 | MySQL、MariaDB 图标显示为空框；弹窗关闭图标显示为实心方块 | 实际绘制失败；资产哈希通过不能替代显示验证 | 09 / 10 / 11 |
| 高 | 基本连接页控件、分区、默认值展示和帮助说明不同 | 相同的 MySQL 配置任务仍需不同操作；模式和环境直接显示 `single` / `dev` | 04 / 10 |
| 高 | 网络页缺 Navicat HTTP 隧道及探活设置；关闭 TLS 时详情仍显示可编辑证书字段 | 配置范围和启用 / 禁用状态不一致 | 05 / 11 |

| 高 | 设置中心为五项平面列表，原版为可搜索、分组的完整目录；关于页结构不同 | 多个设置入口及更新通道 / 自动检查 / 间隔的页面控制项未对齐 | 01 / 13 |
| 高 | 本地表数据页行号从第 10 行起被截断，例如 10、11 都只显示 `1` | 行定位有歧义，需以两位、三位行号验收列宽和绘制 | 15 |
| 中 | 查询空状态仍固定占据较大的结果区，SQLite 状态栏显示 Redis / Nacos 的限制说明 | 编辑面积及反馈与原版不同，提示混入无关数据源信息 | 14 |
| 中 | 外部 SQL 文件侧栏入口缺失，已存查询被放在侧栏底部；对象类别图标数量不同 | 相同任务入口位置不同，尚不能认为侧栏复刻完成 | 02 / 08 |
| 中 | 字段与 DDL 页仍保留数据分页栏；DDL 展示为灰色单行文本 | 各视图的工具和内容展示需要单独对齐；本轮仅确认能打开 | 16 / 17 |

“高”表示阻断当前的一比一验收，并不表示应用崩溃或线上故障。
JVM 管理连接器按用户要求排除，不计入缺失功能。

## 3. 成对截图与具体差异

### 3.1 欢迎页与主窗口

| SuperLink | SuperLink |
| --- | --- |
| ![SuperLink 欢迎工作台](../.cache/ui-compare-2026-10-02/02-superlink-welcome.jpg) | ![Fyne 欢迎页](../.cache/ui-compare-2026-10-02/08-fyne-welcome.jpg) |

原版有主标题、说明、四个快捷动作，以及最近连接、已存查询、最近 SQL 文件、
置顶表、外部 SQL 文件五块卡片。Fyne 欢迎页只有说明文字，且单独占用一个工作标签。
原版侧栏的已存查询和外部 SQL 文件属于树节点，Fyne 只在底部提供已存查询入口。

侧栏分界大约在物理 x=537 / 534，宽度已接近；但 Fyne 全局工具栏位于独立
标题栏下方，原版位于标题栏内，导致后续标签、工具栏和内容整体位置不同。
Fyne 标签初始宽度也明显小于原版，类型摘要缺少原版的独立类型徽标。

### 3.2 数据源选择器

| SuperLink | SuperLink |
| --- | --- |
| ![SuperLink 数据源选择](../.cache/ui-compare-2026-10-02/03-superlink-datasource.jpg) | ![Fyne 数据源选择](../.cache/ui-compare-2026-10-02/09-fyne-datasource.jpg) |

原版选择器约 760 逻辑像素宽，Fyne 约 960，宽约 26%。原版第一行是
MySQL / MariaDB，第二行 Doris / StarRocks；Fyne 第一行 MySQL / GoldenDB，
第二行 PostgreSQL / Oracle。卡片顺序需要逐项对齐，不能只比较类型总数。

原版有最近使用、搜索快捷键提示、分类数量徽标、收藏图钉及 SSL 徽标；
Fyne 当前缺少这些显示 / 操作入口。原版步骤的当前项为绿色，Fyne 三步文字没有
相同的状态区分。原版大号绿色加号、标题与副标题组合也没有对应实现。
MySQL 和 MariaDB 的品牌图案在 Fyne 实际截图中为空框。

### 3.3 MySQL 基本配置

| SuperLink | SuperLink |
| --- | --- |
| ![SuperLink MySQL 基本配置](../.cache/ui-compare-2026-10-02/04-superlink-connection-basic.jpg) | ![Fyne MySQL 基本配置](../.cache/ui-compare-2026-10-02/10-fyne-connection-basic.jpg) |

同为新建 MySQL，原版弹窗约 760 逻辑像素宽，Fyne 约 920，宽约 21%。
原版的连接串为多行输入，有模板、可选说明及“或手动填写”分隔；Fyne 为单行密码
样式输入，按钮和分区也不同。原版模式为中文分段选择，Fyne 为英文下拉，
单机模式下仍显示节点地址。原版生产保护为折叠行及状态徽标，Fyne 当前区域
留有大块空白。页头、页脚、圆角和控件间距均需重新校准。

保存凭据的说明及默认勾选状态也不同。后续复刻显示与交互时应保留现有
凭据保护机制，不能为了视觉相似改为明文保存。

### 3.4 MySQL 网络与安全

| SuperLink | SuperLink |
| --- | --- |
| ![SuperLink 网络与安全](../.cache/ui-compare-2026-10-02/05-superlink-connection-network.jpg) | ![Fyne 网络与安全](../.cache/ui-compare-2026-10-02/11-fyne-connection-network.jpg) |

原版有 SSL/TLS、SSH、代理和 Navicat HTTP 隧道四行，以及超时、后台探活、
间隔和自定义探活 SQL。Fyne 当前为前三行加“编辑”按钮，未显示隧道或探活设置。
SSL/TLS 未启用时，原版显示说明；Fyne 仍显示验证模式及证书字段。
本轮只观察默认关闭状态，没有打开开关、修改证书校验或保存网络配置。

### 3.5 查询编辑器

| SuperLink | SuperLink |
| --- | --- |
| ![SuperLink 新建查询](../.cache/ui-compare-2026-10-02/06-superlink-query-empty.jpg) | ![Fyne 新建查询](../.cache/ui-compare-2026-10-02/14-fyne-query-empty.jpg) |

原版在未选择连接时也能先新建查询。Fyne 在欢迎页、未选择连接时点击顶栏
“新建查询”没有打开新页，见[点击后的实际画面](../.cache/ui-compare-2026-10-02/12-fyne-query-no-selection.jpg)。
只读代码核对确认 `internal/ui/window.go` 的 `newSelectedQuery` 依赖 `selectedProfile`，
无选择时设置“请先选择一个连接”状态；但该状态在欢迎页没有明显可见反馈。
选择本地演示连接后，新查询能够打开。

原版工具栏包含事务选择、执行、保存、AI、更多、搜索、换行、格式化、设置和全屏；
Fyne 当前显示执行、保存、更多、搜索、换行和设置六个按钮，执行图形也由播放
变成纸飞机。原版当前行底色、关键字字重及编辑器行号留白与 Fyne 不同。
两边均未执行的新页，原版使用全高度编辑区和底部计时，Fyne 始终显示空结果区。

此处两边连接和模板不同，不能用 SQL 文本或标签数量来计算视觉差异。
[已有查询结果](../.cache/ui-compare-2026-10-02/07-fyne-query-existing.jpg)
显示本地演示 SQLite 的一行三列及 NULL；这只是恢复结果的显示检查，
本轮没有重新执行该 SQL，不等价于全套查询功能验收。

## 4. 本地库能否打开

本轮实际操作路径：选择“本地演示” → 双击展开连接 → 展开 `main` → 展开“表 2”
→ 双击 `products`。数据页成功显示 6 个字段，分页栏显示当前 100 条、总计 120 条。
字段页显示 6 行元数据；DDL 页显示建表语句。最后应用留在数据页。

![Fyne 实际打开本地 products 表](../.cache/ui-compare-2026-10-02/15-fyne-table.jpg)

[字段截图](../.cache/ui-compare-2026-10-02/16-fyne-table-fields.jpg)与
[DDL 截图](../.cache/ui-compare-2026-10-02/17-fyne-table-ddl.jpg)记录本轮真实打开结果。
数据表行号从第 10 行起被截断为 `1`，需要修复并以多位行号复验。
字段和 DDL 视图还保留数据分页栏，需按视图处理显示。

本轮没有在 SuperLink 中打开同一个 fixture，故表数据 / 字段 / DDL 只做 Fyne
可打开检查，不给出两端一比一通过结论。也未测试用户 MySQL 连接的可用性，
不能以本地 SQLite 结果推断用户业务库是否连接成功。

## 5. 可访问性与未覆盖范围

电脑控制的原生 AX 树能读取 SuperLink 的内部控件；Fyne 仅暴露窗口、系统按钮和
菜单，内部按钮 / 输入框没有出现在本轮树中，因此 Fyne 操作主要使用截图坐标。
这是本轮工具观察，尚未完成 VoiceOver、完整键盘导航或 WCAG 检查。

本轮仅采样以上页面和默认状态，未覆盖深色模式、中文 IME、长文本 / 大结果集、
窗口拖动缩放后的布局、多连接上下文、错误态、所有弹窗及高级工作流。
同尺寸原生对照已经完成这些采样页，完整逐页验收仍未完成。
没有执行用户业务库写入、修改连接凭据、保存新 MySQL 配置、更新原版软件、
Git 提交或推送。本轮仅新增观察文档与 QA 记录，未修改产品代码。

## 6. 下一轮修复与验收顺序

1. 固定主窗口、标题栏、工具栏、工作标签与字体尺寸，并修复空白数据库图标、
   实心关闭图标和多位行号截断，先消除会影响所有页面的差异。
2. 按原版重做欢迎工作台、数据源选择器、连接基本 / 网络页，逐页核对默认、
   选中、禁用、展开、校验失败和保存后状态。
3. 对齐查询工具栏、无连接新建路径、编辑区 / 结果区状态和侧栏入口；对新增
   动作做真实任务验证，不能只补按钮。
4. 补完整设置目录及对应行为，并在两个应用中加载同一独立 fixture，对照表、
   字段、DDL、分页、筛选、编辑预览和受保护提交。

每批修改完成后再获取新的原生截图，固定相同窗口与数据状态验收；本报告作为
修复基线，不能直接用作后续修改的通过证据。完整功能范围继续遵循
[已接受的一比一设计](plans/2026-10-01-superlink-parity-design.md)。
