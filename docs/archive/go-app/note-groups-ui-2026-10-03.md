# 笔记分组弹窗布局优化

原弹窗把新建、重命名、选择和移除纵向挤在一起，按钮贴近输入框，而且新建与重命名共用输入框。

改为两个圆角区域：新建分组和管理已有分组。弹窗使用 540 × 570 的逻辑尺寸，外侧留白 24、卡片内边距 16、输入框与按钮间距 12；高度不足时正文可以滚动。标题带辅助说明，底部单独保留“移除不会删除笔记”的提示和右对齐完成按钮。

选中已有分组后自动填入名称并显示笔记数量。新建和编辑名称使用独立输入框。未填写名称、未选择分组或名称未修改时，相关按钮禁用；重名错误保留输入，成功后更新选项和当前选择。移除分组仍把笔记归入默认分组。

自检：Note 全部测试、输入光标回归测试、分组交互测试通过；`go vet ./internal/ui`、源文件尺寸检查和 `git diff --check` 通过。macOS arm64 原生构建通过。Fyne 软件渲染检查覆盖日间、夜间和 960 × 640 小窗口。原生界面测试窗口受 macOS 台前调度影响，未完成弹窗的原生点击检查；未验证 Windows/Linux 原生窗口。

已更新本地可执行文件、应用包和 macOS ZIP，并保留现有驱动发布清单。重开 SuperLink 后生效。
