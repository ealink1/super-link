## 3. 对照中发现并修复的问题

| 问题 | 修复与证据 |
| --- | --- |
| 自定义行容器嵌入导致原生主机卡片不绘制 | 使用 Fyne 正常容器组合；重新打开独立 QA，七张卡片实际出现 |
| 最后一行仅一张卡片时占满三列宽度 | 布局保留列槽位；原生截图确认最后一张与上两行同宽 |
| 外层默认间距造成多余留白和不齐 | Shell 独立无额外间距布局；统一面板、卡片和输入框间距 |
| 主机名称与 SSH 标识互相挤压 | 按真实文字宽度计算；原生中文 / 拉丁别名不再误截断 |
| 输入框黑色重影与按钮字重过高 | 局部主题消除控件阴影，操作按钮使用紧凑常规字重 |
| 新建表单首屏过松、用户名 / 密码靠下 | 收紧分段和字段间距，弹窗 776 高且小窗口自适应；最新软件截图可见认证字段；最终原生复查待解锁 |
| 改字号未立即重算终端尺寸 | 修改字号时重新布局并通知 PTY；专门回归验证无需缩放窗口即可生效 |
| 关闭 PTY 与更新尺寸发生数据竞争 | 同步 `File.Fd` / 关闭访问，关闭后 resize 返回 `os.ErrClosed`；重复 race 回归及完整相关 race 通过 |

本轮原生证据在 `.cache/shell-redesign/native/`。`hosts.png` 和 `terminal-empty.png` 是实际 QA 窗口；`new-host-first.png` 为收紧前截图，不作为最终表单验收。

## 4. 验证结果

### 已实际操作的原生路径

- 新构建能够打开；原生 SQL / Shell 标题栏切换响应正常。
- 主机卡片全部显示，单张末行不拉伸。
- 中文主机搜索“文档”仅显示匹配主机。
- 新建主机弹窗可打开 / 取消，密码和密钥模式切换正常；未保存额外主机。
- 从空状态启动真实本地 PTY，输入 `echo SuperLink-Shell-UI-OK` 并实际显示输出。

最后一条 ANSI / 中文命令已通过原生粘贴进入终端，但回车后的工具图像输出被截断，重新读取时又遇到锁屏，**未把该次彩色 / 中文执行结果标为通过**。原版本地终端彩色输出已观察；新版 ANSI / 中文仍有自动化与软件渲染证据。

最终设置页的原生保存 / 重启恢复、收紧后表单、小窗口实际缩放、中文 IME 预编辑、远程 SSH / SFTP / 监控点击路径仍待原生复验。后端隔离 SSH / SFTP 测试不等价于实际厂商服务器验收。
