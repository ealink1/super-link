## 本轮已实施

- macOS 原生标题栏使用 AppKit accessory 放置 SQL / Shell 两个大按钮。其他平台与软件测试驱动使用 Fyne 顶部按钮。
- 两套完整内容区独立切换。SQL 的连接、查询、表页和草稿保持；Shell 首次切换才创建，主机列表、筛选和终端会话保留。切换不运行 SQL，不自动连接 SSH，不新建本地进程。
- Shell 独立主机管理：新建、编辑、删除、搜索、分组字段；密码 / 私钥及加密私钥认证；独立的版本冲突保护和加密凭据存储。
- 本地真实 PTY、SSH PTY、多标签终端、终端尺寸同步、ANSI 前景 / 背景 / 粗体 / 斜体、中文宽字符、光标可见性和备用屏幕、1000 行滚轮回滚、常用控制键及粘贴。
- SSH 首次连接显示指纹并要求用户确认；指纹变化阻断连接。修改主机地址或端口后必须重新确认。没有使用忽略主机密钥的回调。
- SFTP 目录浏览 / 上级导航、文件大小 / 权限、流式上传 / 下载、传输字节进度与取消。目录包上限 1 MiB、累计上限 10,000 项；传输缓冲 64 KiB。下载不覆盖本地同名文件；上传使用唯一临时文件及标准 SFTP v3 重命名，拒绝同名目标。
- Linux 服务器基础监控：系统、负载、内存、运行秒数、根目录磁盘；手动刷新，固定只读探针，不插入用户输入。
- 文件和监控使用独立 SSH 通道；通道建立后的取消保留终端。关闭标签 / 退出取消 I/O，回收 PTY / SSH / 子进程并等待后台结束。

## 操作路径

1. 点击标题栏 Shell。空状态可打开系统默认本地 Shell，或选择主机。
2. 主机 → 新建主机 → 填写地址、端口、用户名和密码 / 私钥 → 保存。勾选记住密码后，本机加密保存密码及私钥口令；私钥仅保存文件路径。
3. 点击主机条目 → 连接终端。首次连接需通过可信渠道核实指纹，再确认连接。
4. SSH 标签中的 SFTP 按钮打开文件侧栏。上传选择本地文件；下载选择本地目录。取消传输保留终端。
5. SSH 标签中的服务器监控按钮读取 Linux 基础指标。本地会话没有 SFTP / 服务器监控，按钮禁用。
6. 切回 SQL 后仍可回到原来的 Shell 标签。关闭会话会终止其进程或连接；应用重启不自动恢复远程会话或执行命令。

## 原生验收及限制

独立 QA 应用已启动，并通过 Fyne 事件循环健康握手。电脑控制返回 **Mac 已锁定，无法自动解锁**，因此原生标题栏位置、实际点击 / 焦点 / 缩放及系统输入法尚未完成本轮自检。已请求用户手动解锁。不能把构建成功或软件截图当作标题栏视觉通过。

安装的 iShell Pro 已通过辅助功能树观察主机和终端页，但截图返回后台缩略窗口；尚无合格的完整窗口并排对照。首阶段保留其主机 / 终端 / 标签 / 辅助面板流程参考，不宣称界面风格已一比一完成。

当前终端复制操作复制可见屏幕；鼠标文本选择、完整交互程序鼠标协议和原生中文预编辑待阶段 2 验收。监控不是完整实时仪表盘。SFTP 为 v3；网络完全断开时临时上传文件清理可能失败，错误会返回，不把失败写成成功。

Windows 本地 PTY 当前明确返回不支持，不能用普通管道冒充 ConPTY。macOS / Linux 的本地实现中，仅 macOS 已运行实际测试。其他平台和真实厂商 SSH 服务未验证。
