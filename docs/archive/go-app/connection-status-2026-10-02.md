# 连接状态圆点自检

> 名称与命令已于 2026-10-03 统一为 SuperLink；历史截图、产物哈希和验收结论仍对应记录当日版本，本次更名验证见 [完整更名记录](superlink-namespace-2026-10-03.md)。

日期：2026-10-02。应用：SuperLink 0.1.0。

SQL 左侧连接和数据库节点右侧新增带淡色外圈的状态点：绿色为已建立会话，红色为未连接 / 失败 / 会话已丢弃，黄色为正在建立连接。其他树节点不显示，树行复用时清除旧圆点。明暗模式随共享主题刷新。

状态来自 Engine 的真实会话生命周期，既覆盖左侧展开，也覆盖直接查询、导出、表数据及写入失败后丢弃会话。临时测试连接关闭后不会留下绿色状态；元数据权限错误不等于会话已断开。多个范围的会话按仍有可用连接优先聚合。没有增加网络心跳或定时轮询；服务器在空闲期间断线，要等后续操作发现并丢弃会话后才会变红。

断开成功后会清除缓存库节点并收起分支，重新展开会重新建立连接。线程安全快照和合并通知只携带状态；UI 在 Fyne 线程刷新，监听器随窗口关闭取消并等待退出，不计入待完成的 I/O 作业，也不无限排队。
