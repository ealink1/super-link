## Findings

- [P1] 监控内容和密度仍与原版有明显差距。位置：`shell_monitor.go`。原版有 CPU 利用率、网络收发、历史图表、分区和网卡；当前有负载平均值、内存、根目录磁盘、运行时间四张快照卡。证据：`monitor-panel.png` / `monitor-full.png`。影响：侧栏下半部明显空，无法复刻原版连续监控体验。修复：领域层增加有界、可取消的 CPU / 网卡采样，UI 增加历史曲线和分类视图；指标卡压缩到原版的紧凑密度。不能用随机曲线或把 load average 写成 CPU 百分比填补。
- [P2] 文件工具条不完整，垂直层级仍有差异。位置：`shell_files_view.go`。原版顶部有紧凑指标、单行路径动作、隐藏文件 / 同步 / 目录上传等；新版仍为路径输入、动作行、搜索、三列表格。证据：`files-panel.png`，新版长名称 / 列宽另见 `files-small-dark.png`。修复：结合真实对应文件能力继续复刻紧凑路径工具区与顶部指标，不直接增加没有行为的按钮。
- [P2] 会话高级动作未达到原版完整工具条。位置：`shell_session_chrome.go`。本轮仅为已接通的 SFTP、监控、重连和字号；原版还显示分屏、快捷命令、隧道、历史、录制等入口。证据：全图组合。修复：按已接受的 Shell 分期计划实现对应动作，再恢复原版工具栏位置与间距。

1. 早期 [P2] 连接弹窗顶部过高、节点向中间收缩、多出水平忙碌条。修复：标题 16px 内边距，节点横跨弹窗，头部约 130px，Activity 放入标题圆形徽章，页脚固定。后续证据：`connect-final.png`，同为 512×400、通道打开阶段。
2. 早期 [P2] 两行终端工具区挤占高度、侧栏为固定高度孤岛。修复：32px 单行底栏、320～420px 自适应全高侧栏。后续证据：`monitor-full.png` 和 `files-full.png`，小窗夹具 960×640。
3. 早期 [P2] 双行文件标签不便扫读。修复：36px 虚拟化三列行、搜索与文件索引映射。后续证据：`files-small-dark.png`，长文件名省略且大小 / 时间仍可见。
4. 原生 [P2] 长会话名覆盖关闭按钮。修复：12px 正常字重、实际字体测量到 100px，保留关闭按钮区域。后续证据：`monitor-final-dark.png` / `files-final-dark.png`。
5. 原生 [P2] 底栏连接状态和主机身份提前省略。修复：主机信息和状态文本占满 Border 中间区域。后续证据：`monitor-final-dark.png`，主机名、端点及“已连接”可见；`auth-failed.png` 记录失败路径。
6. 软件 [P2] 小进度条默认百分比溢出。修复：条形进度不渲染默认文本，百分比显示在独立指标值上。后续证据：`monitor-small-light.png` / `monitor-small-dark.png`。
