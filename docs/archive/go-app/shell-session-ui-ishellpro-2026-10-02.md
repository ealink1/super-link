# SuperLink SSH 会话界面调整

> 名称与命令已于 2026-10-03 统一为 SuperLink；历史截图、产物哈希和验收结论仍对应记录当日版本，本次更名验证见 [完整更名记录](superlink-namespace-2026-10-03.md)。

日期：2026-10-02。项目：独立 Go / Fyne 的 SuperLink。参考：本机安装的 iShell Pro 原生 SSH 终端、监控与 SFTP，以及用户提供的连接进度截图。

## 已实现

- 512×400 的四阶段连接弹窗：建立连接、身份验证、打开通道、连接就绪。进度来自真实 SSH 操作，取消会关闭当前连接；失败显示对应阶段并允许重新连接。日志仅使用固定阶段说明，不包含密码、私钥或认证输出。
- 紧凑的单行会话标签、块状终端光标、32px 底部操作栏。连接状态用红 / 绿点显示；字号可直接加减，保留用户已设置的字号。
- 右侧面板占桌面宽度约 29%，限制在 320～420px，全高显示并可收起；切换面板不会重建 SSH 会话。
- 监控从文本列表改为主机信息和 CPU 负载、内存、根目录磁盘、运行时间卡片。仍是手动刷新快照；CPU 值是负载平均值，不是利用率。
- SFTP 改为名称、大小、时间三列，可按名称搜索，文件夹优先排序。上传 / 下载 / 取消延续现有服务；搜索后选中项映射到正确文件。
- 日夜主题继续与 SQL 共用，绿色主色沿用用户要求。

## 自检

`go test ./...`、`go test -race ./internal/infra/shell ./internal/ui`、`go vet ./...`、架构 / 源码体积 / Fyne 固定版本 / 图标来源校验、`git diff --check` 和 macOS arm64 原生构建均通过。

电脑控制在独立 QA 应用、独立工作区和仅监听本机的 SSH 夹具上验证了成功、终端输入回显、取消、认证失败、监控和 SFTP。没有修改日常连接或向业务主机输入测试命令。日 / 夜、大 / 小窗口的软件截图另作布局证据，不冒充真实监控数据或跨平台验证。

## 仍存在的复刻差距

| 区域 | iShell Pro 原版 | 当前 SuperLink |
| --- | --- | --- |
| 监控 | 自动采样、CPU 利用率、网络速率、历史曲线、CPU/GPU/MEM/DISK/NET 分类 | 手动快照、负载平均值、内存、根目录磁盘、运行时间 |
| SFTP | 顶部紧凑监控、路径面包屑、隐藏文件 / 同步 / 上传目录 / 批量操作 | 路径输入、上级、名称搜索、单文件上传下载与取消 |
| 终端高级工具 | 分屏、快捷命令、隧道、历史 / 录制等 | 本轮接入 SFTP、监控、重连、字号与连接状态 |
| 视觉细节 | 原版字体、旋转圆弧、原版专用配色 | 共用字体与主题、原生 Activity 和标准 Lucide 图标 |

完整一比一验收状态见根目录 `design-qa.md`。本轮完成的是 SSH 连接和会话的基础视觉重做，不能标记全部 iShell Pro 功能或界面已完成。

## 本地使用

已更新本地 `bin/SuperLink.app` 与 `bin/superlink`。运行中的日常应用继续使用旧进程；关闭后重新打开包即可载入新界面。保持原有应用标识与数据目录，不需要重新保存业务连接。没有提交、推送或发布 GitHub Release。
