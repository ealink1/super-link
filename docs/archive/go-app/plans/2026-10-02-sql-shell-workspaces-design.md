# SQL / Shell 独立工作区及 iShell Pro 功能计划

用户确认：所有 iShell Pro 功能纳入，分阶段持续实现。保持独立 Go + Fyne 项目，无 JVM / Wails / Electron。不得把新 Shell 页面混进 SQL 查询标签。

## 工作区切换

macOS 在原生标题栏的应用名称位置提供醒目的 SQL、Shell 切换按钮，保留系统窗口控制和拖动。使用 Fyne NativeWindow 与 AppKit 标题栏 accessory，不修改固定 Fyne 副本。其他平台和无原生上下文的测试驱动用顶栏按钮。切换替换整页内容；SQL 原有连接树、查询、表和草稿保持，Shell 主机、会话和辅助面板独立保留；切换不会重新连接或执行指令。

## 参考依据

已安装 `/Applications/ishellpro.app` 的原生辅助功能树显示“主机、终端、指令集、笔记随记、设置”入口；终端空状态提供本地壳、SSH / 串口、多标签和分屏入口。主机页采用分组 / 标签导航、搜索、协议过滤和网格 / 列表布局。当前原生截图返回后台缩略窗口，不能用作准确视觉验收；后续需要补齐完整窗口截图。

官方资料：[界面概览](https://www.ishell.cc/zh-CN/docs/interface)、[终端标签与分屏](https://www.ishell.cc/zh-CN/docs/ssh-multitab)、[SFTP](https://www.ishell.cc/zh-CN/docs/sftp)。引用其交互和能力作为参考，不复制商业资产、登录服务或宣传性能数字。

## 分层与质量约束

Shell 独立领域模型；主机元数据独立存储，密码 / 私钥口令复用现有加密 vault，不读取 iShell Pro 配置或凭据。终端传输与 SSH / SFTP 位于独立 infra 包；UI 仅处理交互、渲染和异步结果。首次 SSH 主机指纹需要用户明确信任，变化阻断连接，不使用 InsecureIgnoreHostKey。取消必须关闭网络连接、终端、文件任务并等待后台退出。输出、屏幕、传输并发和监控结果有上限。

各阶段持续维护已实现 / 部分实现 / 未实现 / 已验收状态。未实现功能不放假可用按钮，不宣称一比一完成。浏览器测试、提交、推送和线上发布仍需要用户明确要求。
