# 主页面顶部样式

按用户提供的参考图调整 SQL / Shell / Note 标签及 SQL 工具栏。

- 工作区标签紧凑排列，使用常规字号，选中标签显示蓝色文字及文字宽度的细下划线，移除分段底色。
- SQL 工具栏按用户最新参考图采用图标在上、12 号文字在下的按钮，新建查询以蓝色突出；所有按钮均无常驻底框。工具栏高度 56，缩小上下留白，保留图标与文字的相对间距。
- 管理连接分组、驱动管理之后增加竖向分隔线，工具栏底部增加横向分隔线。
- 保留现有操作回调和原生 macOS 窗口控制，兼容深色主题。
- 使用 UI 回归测试、静态检查及 macOS 原生构建验证，不使用浏览器测试。
