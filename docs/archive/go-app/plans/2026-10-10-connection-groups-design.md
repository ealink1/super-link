# 连接分组管理

参考用户提供的管理连接分组截图，适配原生 Fyne 和 SuperLink 品牌。

- 980×630 圆角模态窗口：标题和关闭按钮；左侧 250px 分组区，右侧连接表。
- 左侧新建分组按钮、绿色选中状态、分组名称及数量；新建的空分组保存到本地设置。
- 右侧按当前分组展示连接名称、公开地址、添加时间、编辑和删除操作。
- 添加时间和连接名称支持正反向排序，地址支持正向排序；勾选及全选后可批量移动到其他分组。
- 编辑打开现有连接配置；删除需确认，并断开会话、移除相关文档。
- 读取与修改在后台任务中执行，界面立即展示；批量移动通过数据库事务和版本检查避免部分提交，不读取或改写凭据。
- 新连接开始记录真实创建时间；既有连接没有时间信息时显示“—”，不推测历史时间。

验证：应用层持久化、创建时间保留、冲突回滚；原生 UI 分组加载、排序、移动、全选、单元格渲染、确认删除、空状态；完整 UI 测试、静态检查、原生构建。禁止浏览器测试。

## 连接树分组展示

补充参考用户提供的侧栏截图：非空分组作为一级文件夹节点，连接数量以相邻徽标显示，组内连接缩进；未分组连接保留在一级。首次出现的分组默认展开，后续刷新保留展开状态。按分组名搜索保留其连接，定位连接时展开祖先分组。分组本身不具有数据库会话，只提供管理和刷新菜单，展开不会请求数据库。删除空分组节点时保留实际连接节点与其已加载子树。

新增原生测试覆盖分组层次、数量、首次展开、无请求展开、刷新保留子树、搜索、定位、徽标复用，以及连接移出分组后的清理。截图：`/tmp/superlink-groups-qa/navigator-groups.png`。

## 新建分组弹窗

参考用户的新建分组截图，使用 520×480 原生圆角弹窗：绿色文件夹标识、标题和说明、关闭按钮、卡片内必填名称/可选父分组/连接勾选列表，以及取消和绿色确定按钮。连接列表根据真实名称和公开主机地址展示，较长列表可滚动。读取数据在弹窗打开后异步进行，名称为空时确定禁用，重复或冲突错误在卡片内显示。

父分组元数据保存到本地设置，兼容此前只有组名的记录。创建分组、保存父关系、更新所选连接通过同一事务提交，失败全部回滚。连接树支持父子节点、汇总连接数量和空分组；管理器侧栏按层级缩进。弹窗取消不写数据，成功后刷新管理器和连接树。
