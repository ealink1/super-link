# 所有表列表多选

普通点击单选，Ctrl + 点击切换当前表的选中状态，macOS 兼容 Command + 点击。选中状态以完整表身份（库、Schema、名称、种类）保存，整行持续高亮，状态栏显示选中数量。悬停使用较浅颜色，不覆盖选中颜色。

右键点击已选中的表保留选择，右键点击未选中的表切换为单选。右键操作仍作用于菜单对应的表。筛选或刷新后移除不再可见的选择，保留仍存在的表。双击保持打开表数据。

通过原生事件及渲染测试验证增选、取消、普通单选、跨列高亮、右键保留和筛选清理，进行静态检查、原生构建并重启，不使用浏览器。

## 即时响应和拖动选择

在 MouseDown 中立即应用选择，后续延迟 Tapped 不重复切换，双击继续打开数据页。高亮通过缓存的单元格背景直接绘制，仅刷新颜色变化的背景，不刷新表格布局、文字和图标。

按住左键跨行拖动选择起点至当前行的连续范围，反向拖动缩小或转向范围；Ctrl/Command 拖动保留按下前选择作为基线。释放或 DragEnd 结束范围选择，筛选重置拖动锚点。原生事件测试覆盖按下即时响应、延迟点击不重复切换、选择及悬停零单元格重建、正反向拖动、增选及释放。
