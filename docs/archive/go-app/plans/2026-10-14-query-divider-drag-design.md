# SQL 编辑区/结果区分隔条拖动

原有主题将 Fyne 的分隔条厚度设为 1 像素，真实鼠标很难命中，表现为上下拖动没有效果。

仅为 SQL 查询上下分栏使用局部主题，将实际命中厚度扩至 8 个逻辑像素。命中区域背景透明，正常及悬停时都显示贯穿查询区宽度的 1 像素分隔线，使用适配亮暗主题的柔和灰色；分隔条专用主题不改变按钮等控件的悬停样式。继续使用 Fyne Split 的拖动、光标、范围限制和默认比例；其他控件的颜色、字体、尺寸跟随应用主题，不改变其他分栏。保留长 SQL 的行号高度约束和滚动同步。

回归测试在分隔条起点下方 3 像素处向下/向上拖动 100 像素，确认两块区域高度变化并仍然可见，同时继续验证长多行、长单行与换行切换。以独立数据目录运行原生窗口，再通过鼠标实际拖动验证两方向效果；完成相关竞态、全量测试、静态检查、构建与自动重启。不使用浏览器，不提交或发布版本。

视觉回归检查亮色、暗色及往返切换，普通和悬停状态都不绘制横贯窗口的粗灰带，整条分隔线从左到右持续可见。
