# SuperLink Note 工作区

用户要求：先查看本机 iShell Pro 笔记功能，在标题栏 Shell 右侧加入独立 Note 菜单。使用纯 Go / Fyne，沿用 SQL / Shell 共用日夜主题，不导入原版笔记或凭据。

## 观察与布局

电脑控制已打开原版笔记页：左侧约 306px 为搜索、新建与分组入口、按更新时间排列的笔记摘要（不含原版侧栏导航）；右侧顶部为状态 / 分组 / 更多菜单，下面是大标题、格式工具栏和编辑正文。新建菜单提供富文本和 Markdown 两类笔记。只查看原版，没有创建或修改用户笔记。

原版商业富文本编辑器无法直接复用到 Fyne。当前默认方案为 Markdown 编辑、格式工具栏、预览和分屏，保留列表 / 标题 / 工具栏的布局；已异步询问用户是否优先需要富文本或两种编辑方式。独立 Note 比嵌入 Shell 更符合用户菜单定位；本地加密存储比仅有临时编辑器更符合笔记使用。

## 实现与验收

1. 标题栏和跨平台 Fyne 菜单增加第三项 Note，三个工作区缓存各自 UI 状态，按需加载；切换保留 SSH 和 SQL 页面。
2. 独立 Note 领域和应用服务。整本笔记、标题、标签、分组与回收站加密保存，SQLite 只记录不透明引用和版本。原子发布新引用，乐观版本检查避免覆盖。限制单篇正文 256 KiB、300 篇、50 分组、序列化总量 6 MiB。
3. 搜索标题 / 正文 / 标签，分组增改与移除（内容移到默认分组），新建、改名、移动、回收站恢复；导入 / 导出 Markdown。编辑预览可用，原版数据不自动导入。
4. 自动保存防抖与合并，所有 I/O 后台执行；保存失败保留内存编辑并显示错误。正常退出 / 停止事件循环后都有最后快照保存，保存失败阻止正常关闭。
5. 真实持久化 / 加密、冲突与失败、分组 / 回收站、中文格式编辑、最后一次修改退出、主题 / 小窗、三工作区切换回归；隔离数据目录进行原生操作与布局对照。

不提交或推送，不使用浏览器测试。

## 已实现范围与后续

Note 首版使用 Markdown，未实现原版富文本所见即所得、云端同步或 AI 笔记。预览中的图片只显示说明文字，不自动读取本地文件或联网加载；显式 HTTP(S) / mailto 链接可点击。导出选择文件夹和文件名，同名文件经确认后原子替换。

回收站内可恢复；永久删除需要明确确认。移除分组不删除文档。新建、编辑标题 / 正文 / 标签和分组操作会自动保存，750ms 防抖；切换 SQL / Shell 保留当前编辑。无法解密时不开放新建来覆盖旧库，保存失败保留未保存编辑。

笔记本使用工作区现有本地 AES-GCM 凭据设施，SQLite 仅保存版本和引用。备份 / 迁移必须同时保存 `state.sqlite` 和完整 `credentials` 目录，尤其 `master.key`；不依赖系统钥匙串。Markdown 导出为普通明文文件，由用户选择位置。

已验证：应用 / UI / 文件导出测试、竞态检测、自动保存期间继续编辑、退出最后一次修改、外部冲突拒绝覆盖、失败保留原目标、中文格式及撤销、分组 / 回收站、明暗和 960×640 布局；原生隔离应用写入、保存和重新启动读取。Linux / Windows 图形交互未实测。
