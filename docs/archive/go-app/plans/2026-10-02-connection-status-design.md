# 连接状态圆点

在 SQL 侧边栏的连接和数据库节点右侧显示带淡色外圈的小圆点，绿色表示存在已建立的应用会话，红色表示未连接或会话已丢弃，黄色表示正在建立连接。表 / 分类 / schema 等其他节点不显示圆点。日间、夜间随应用主题刷新。

状态来自 application Engine 的实际会话生命周期；配置保存、测试连接后关闭及恢复查询草稿不代表连接成功。多个数据库范围分别建会话时，只要仍有已建立的会话，连接整体保持绿色。元数据权限错误不等于断开；真正被 Engine 丢弃的查询 / 导出 / 写入会话恢复为红色。状态只描述应用已知会话，不额外轮询用户服务器。

Engine 提供线程安全的状态快照及容量为一的合并通知，通知不携带密码或错误详情。UI 接收通知后在 Fyne 线程刷新已有树行。监听随窗口任务管理器取消并等待退出，不增加网络请求、定时器或每帧轮询。

验证连接开始 / 成功 / 失败 / 重试 / 断开、多个范围和关闭行为，并运行竞态检查；检查树行复用、节点过滤、实际查询触发的状态同步、明暗颜色与圆点布局。使用隔离的本地演示数据验证原生界面，不执行用户业务库 SQL。修改后重新构建并启动 SuperLink。
