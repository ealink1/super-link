# 数据库节点导出

数据库节点右键提供“导出数据库”，选择目录后将全部表的建表 DDL 和可写列数据导出为单个 SQL 文件。排除视图、存储过程、触发器和权限，并在对话框中说明范围及无一致性快照限制。

逐表流式读取数据，先输出全部建表结构，再输出 INSERT。MySQL/MariaDB 脚本选中目标库并暂时关闭外键检查，结束时恢复原值。恢复时目标数据库应已存在。

后台任务带取消、30 分钟超时和连接版本保护；对象数量最多 10000，全文件最多 8 GiB，单表遵循现有数据编码限制。写入同目录临时文件，全部成功后发布，不覆盖已有文件，失败清理临时文件。进度窗支持停止。

验证 SQL 结构与数据生成、流式目标和版本参数、失败与取消的临时文件清理、已有文件保护、数据库节点菜单入口、静态检查及原生构建。不使用浏览器，不对用户真实数据库执行测试。

## 两种导出入口

数据库右键提供“导出全部表结构 · SQL”与“备份全部表 · 结构 + 数据 SQL”。两者共用同一导出服务与文件保护；结构模式不调用行流式查询，不输出 INSERT，备份模式保留结构和全部可写列数据。结构模式测试使用会失败的行流源，确保不会读取数据。

## 详细进度

导出服务以回调报告阶段、当前表、总表数、完成表数、累计行数、当前表行数和已写字节。按已完成的结构/数据表级任务计算进度，文件发布前最多 99%，发布成功后 100%。行级通知最多每 100 毫秒一次，阶段切换与表完成立即通知；UI 通过 Fyne 调度更新，弹窗关闭后忽略排队通知。支持停止。

测试覆盖结构/数据两种模式的阶段、表名、行数、字节、进度单调性与失败不报告完成，以及 UI 文本详细信息。
