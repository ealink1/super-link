# 紧凑工作标签

用户要求：标签缩短，去掉下面的连接 / 数据库栏，只在鼠标停留时显示所属连接和库。

将工作标签从 166×46 改为 132×32（Fyne 逻辑尺寸），保留单行名称、关闭按钮和选中时的绿色顶线。长名称显示省略号，提示保留完整名称。查询、表数据、表设计和导入页的提示从各自页面的连接 / 数据库读取；切换查询连接或数据库后重新生成。

使用工作区内共享的被动提示层，不使用会拦截整张画布鼠标事件的 PopUp。提示不会改变窗口最小尺寸，不为每个标签创建计时器或后台线程。离开、点击、切换或移除标签时隐藏，移除标签时清除共享层引用及选中 / 关闭回调。

验证单行尺寸、悬停内容、首次点击选中与关闭、元数据更新、长名称换行与边界、主题切换、弹窗期间不显示、关闭后释放引用。跑 UI 测试、相关竞态测试、静态检查和 macOS 原生构建；按此前授权重启默认工作区检查实际标签，不执行用户 SQL。
