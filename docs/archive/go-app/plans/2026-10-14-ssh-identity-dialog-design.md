# SSH 主机指纹确认框

按用户提供的 HTML 参考实现原生 Fyne 弹窗：圆角面板、盾牌标题与首次连接标记、连接目标卡片、SHA256 指纹分块、复制操作、可信渠道核实提示、记住选项和独立底部操作区。使用实际握手返回的主机信息和指纹；主题跟随应用日间/夜间设置。小窗口滚动正文，保留底部确认和取消按钮。

指纹每四个字符一组展示，首尾加粗，复制时保留完整原始 SHA256 字符串。Esc 取消，Enter 确认，按钮保留 Fyne 焦点与禁用语义。取消、关闭及重复确认只能完成一次回调；所属终端标签关闭时同步销毁弹窗。

默认勾选“信任此主机并记住”，继续使用 SuperLink 的本地主机指纹记录，文案不声称写入系统 known_hosts。取消勾选时只给本次重试提供指纹，绑定所展示主机的 ID、修订号、地址、端口和用户名；重连重新加载记录并再次核实。服务器已有指纹发生变化时仍阻止连接。所有主机存储与网络操作继续放在后台任务中。

确认后使用真实连接进度弹窗；HTML 中的模拟成功、延时和重新演示不进入产品。

验证：真实本地 SSH 握手测试记住与本次信任、修订冲突及再次连接；测试原始复制、Esc/Enter、单次回调和标签清理；验证大小窗口及明暗主题布局、相关竞态、全量 Go 测试、静态检查、原生 macOS 构建与截图。按项目要求安装并重启最新代码，不使用浏览器，不提交或发布版本。
