# SQL / Shell 共用日间与夜间主题

用户要求两套工作区使用相同主题，在 macOS 窗口控制按钮右侧、SQL / Shell 左侧增加模式切换。

- 共用现有应用 `Theme` 的背景、面板、文字、边框、选中和主色；保留各工作区布局与字号。
- macOS 原生标题栏新增太阳 / 月亮按钮；其他平台和软件驱动使用同位置的 Fyne 按钮。
- 所有入口（标题栏、SQL 外观设置、Shell 外观设置）改变同一状态。
- 选择保存到当前工作区 SQLite 设置，后台串行写入；加载期间的用户选择不被旧值覆盖，正常退出再保存最终状态。
- Shell 文本、面板、图标、终端默认前景 / 背景动态刷新；终端 ANSI 显式颜色保持，查询与终端内容和会话不重建。
- 验证主题往返、工作区切换、打开中的表单、终端 ANSI、快速连续切换和重载；运行相关竞态 / 静态检查与原生构建。无需浏览器测试。
