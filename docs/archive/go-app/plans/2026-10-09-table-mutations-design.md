# 表右键操作

在左侧表导航和数据库“所有表”列表共用的右键菜单中新增删除表、清空表、截断表。

- 删除表执行 DROP TABLE，清空表执行 DELETE FROM，截断表执行 TRUNCATE TABLE。
- SQL 标识符使用现有方言引用方法；视图和不支持的方言禁用操作。SQLite 禁用截断表。
- 使用 Engine.Execute 的连接版本、只读、访问保护及一次性确认机制；确认对话框显示连接、表、操作影响和 SQL。
- DROP/TRUNCATE 受结构修改保护控制，DELETE 受脚本执行保护控制。
- 后台任务使用带超时的上下文；执行完成后刷新导航、列表和相关表数据页，删除表后关闭相关数据页。
- 验证 SQL 引用、能力限制、菜单保护和执行前确认，运行相关包测试、静态检查及原生构建。无需浏览器测试。

## 连接生命周期修复

执行成功后集中刷新导航和数据库列表，每个列表只刷新一次，避免紧接着取消刚启动的目录请求。执行层仅在 database/sql 明确返回 ErrConnDone（语句未发送）时重建远程 SQL 连接一次；通用网络错误和执行结果不确定的写入不重试。驱动代理传回的同名精确错误在运行时恢复为该哨兵。SQLite/DuckDB 不自动重建，避免丢失内存库。重连前后检查连接版本；重连失败保留错误和失败状态。
