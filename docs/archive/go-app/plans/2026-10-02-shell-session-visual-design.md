# SSH 会话界面对照 iShell Pro

用户已要求在独立 SuperLink Fyne 项目中复刻 iShell Pro 的 SSH 连接和终端界面，并继续使用电脑控制与原生自检。沿用共用日夜主题、真实会话、安全指纹确认和已有文件 / 监控能力，不引入浏览器或 WebView。

## 参考与范围

- 用户提供的 SSH 连接进度截图：四阶段、完成 / 活跃 / 等待状态、带颜色的连接日志、固定取消按钮与圆角面板。
- 已安装 iShell Pro 的终端：紧凑标签和顶部操作、右侧可收起的监控 / 文件面板。先前完整本地终端参考在忽略的 `.cache/shell-redesign/reference/terminal-local.png`。
- 本轮实际打开 `cc.ishell.pro`，已读取 SSH 终端、监控和文件入口的 AX 状态。通过原生全屏取得 SSH 终端、监控和 SFTP 完整截图，保存在忽略的 `.cache/shell-session/native/ishell-ssh-monitor.png` 与 `ishell-ssh-files.png`。仅查看业务会话，没有输入命令或改动业务文件。

可选方向：仅修饰底栏不能改善主要层级；复制全部按钮会把未实现的高级能力混入当前流程；采用原版布局并接入已有真实能力最符合当前任务。选第三种：终端动作移到紧凑工具区，监控 / 文件面板按原版密度组织，进度由实际传输阶段驱动。

## 实施

1. SSH 传输新增有类型的进度事件：建立连接、身份验证、打开通道、连接就绪；现有 `OpenSSH` API 保留。事件不带密码、口令、私钥、DSN 或认证原始错误。
2. 连接弹窗采用四节点进度、日志区和固定页脚；取消实际取消当前连接；失败保留明确阶段和重试入口；成功关闭弹窗并聚焦终端。事件经过有界合并队列，在 Fyne 线程更新，结束后停止监听。
3. 紧凑终端标签、工具栏、底部状态与右侧面板；切换工作区和主题不重建会话。监控只显示实际返回的指标，文件行为延续已有 SFTP 服务。
4. 隔离 SSH 夹具验证成功、认证失败、通道失败和取消；UI 验证顺序、日志预算、关闭后不更新、主题切换和窄窗口布局。查看同状态软件 / 原生截图，记录无法验收的平台和缺失高级功能。

不提交、不推送，不在用户业务主机执行测试命令。原生验收使用独立工作区和本机隔离 SSH。

## 本轮验收与后续

已实现真实阶段弹窗、取消与错误状态、紧凑终端标签和单行底栏、全高自适应右侧面板、监控卡片、可搜索的 SFTP 三列表格。修正了原生渲染发现的标签关闭按钮遮挡、状态和主机名称提前截断。

本机隔离 SSH 原生验收覆盖成功、输入回显、取消、认证失败、监控读取和空 SFTP 目录；软件渲染检查日 / 夜模式以及 1470×826、960×640 布局。全量测试、相关竞态测试、静态检查和 macOS arm64 构建通过。

整体 iShell Pro 一比一验收尚未完成：实时 CPU 利用率 / 网络速率 / 曲线与监控分类页、文件管理顶部指标和完整工具条、终端高级动作仍在后续阶段。所有差距及证据列在根目录 `design-qa.md`，不能用本轮测试通过代替完整视觉一致性通过。
