# 终端鼠标拖选（2026-10-19）

## 修改

终端此前只实现点击聚焦和滚轮事件，没有 Mouseable/Draggable。新增左键按下、拖动、释放处理，支持正向/反向跨行选择及主题高亮，选区按终端显示格定位；中文宽字符的续格会对齐完整字符，组合字符保留原文。

Cmd+C 与 Ctrl+Shift+C 复制选区；没有选区时保留现有整屏复制行为，Ctrl+C 仍作为终端中断。单击、新输出、输入、终端尺寸变化会清理旧选区。拖到上下边界外可自动滚动历史，动画在 UI 线程执行，松开鼠标、失焦、会话关闭或切换至后台时停止。

远端启用鼠标模式时转发左键点击/释放及其支持的拖动事件；按住 Shift 可强制本地选字。Vim 原有鼠标滚轮及 Home/End 编码继续保留。

## 验证

使用 Fyne 测试驱动验证正反向跨行选中、复制范围、中文/组合字符、ANSI 颜色与选区背景、历史边缘自动滚动、释放/关闭清理、Vim SGR 鼠标事件、按下后远端重绘不打断拖动、Shift 本地覆盖。未连接用户服务器，未使用浏览器。

执行普通全量 Go 测试、终端与会话生命周期相关 race 测试、go vet、架构及源码长度检查、Fyne 来源校验，以及 macOS arm64 原生构建并自动重启。Windows/Linux 未做原生手动交互验证。
