# 中文备用字体内存回退修复

日期：2026-10-12；macOS arm64，真实 Fyne/OpenGL 窗口，1320 × 860 逻辑尺寸。

用户截图主进程为 429.8 MB。随后运行进程的 `vmmap -summary` 测得
453.5 MiB footprint，其中 IOSurface、图形分配及图形未映射内存合计约
132 MiB；这些计入主进程。不同运行状态不能直接作为优化前后百分比。

隔离欢迎页的存活堆采样约 157 MiB，约 130 MiB 经由系统字体回退保留。
本机 zh-CN 的语言选择加载 Arial Unicode，以及粗体 Songti；TrueType
轮廓点及字体表占主要开销。桌面主字体只覆盖部分字符，中文因此再次触发
这条高内存路径。单独改变回退顺序没有解决问题，最终保留原回退顺序，
在系统回退之前按需提供项目原有的完整 CFF 中文字体。

英文、数字继续使用系统主字体。中文优先使用现有 regular / semibold
资源；未覆盖字符仍可走原系统语言和逐字回退。没有裁剪中文字符、降低
Retina 清晰度或添加产品周期强制 GC。既有字体许可证和来源保持不变。

| 原生固定场景 | 修复前进程 footprint | 修复后进程 footprint | 修复前存活 Go 堆 | 修复后存活 Go 堆 |
| --- | ---: | ---: | ---: | ---: |
| 欢迎页，40 秒 | 236.16 | 137.94 | 157.43 | 51.86 |
| 合成终端及综合监控，每 3 秒刷新，90 秒 | 372.03 | 209.39 | 172.04 | 65.58 |

单位均为 MiB。进程值取诊断 GC **之前**；存活 Go 堆取结束前单次诊断
GC 之后。监控两组使用同一合成数据、同一界面代码，只切换是否提供
紧凑字体回退；每组约 30 次刷新，进程占用下降约 43.7%。短时测量
不能代表更多查询标签、大结果集或长期运行的内存上限。

测量使用独立私有工作区，没有读取真实连接、访问业务库、启动浏览器
或开放 HTTP profiler。欢迎页使用 `tools/memory-probe`；监控临时夹具
源代码及原生测量二进制留在 `/tmp/SuperLink-memory-20261012-monitor-fixture-source`
和 `/tmp/SuperLink-native-monitor-memory-{before,after}`，临时源码已从项目移除。
JSONL 与 heap profiles 位于 `/tmp/SuperLink-memory-20261012-{before,cjk,monitor-before,monitor-after}`。

验证覆盖中文常用字符、粗体与等宽样式、保留桌面主字体、嵌套局部主题、
明确指定字体的文字、回退资源替换时缓存失效，以及终端中文字形、监控
数值和全部应用测试。Fyne painter/cache 的 race 检查、静态检查与固定
副本清单校验通过。原生构建用于最终运行；Windows / Linux 内存数值
未在本机测量。
