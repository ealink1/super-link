# SuperLink AI 普通问答与自检

## 使用

重开本地 `bin/SuperLink.app`，点击右上角灯泡，在右侧打开 SuperLink AI。首次点击 **AI 设置**，填写 OpenAI 兼容接口的基础地址、模型和 API Key。地址通常以 `/v1` 结尾，也接受完整 `/chat/completions` 地址，不重复添加路径。本地 Ollama 示例为 `http://localhost:11434/v1`，模型填写本机已安装的名称，Key 可留空。

保存配置不会发送测试请求。输入问题后点击发送，或使用 Ctrl / ⌘ + Enter；Enter 本身换行。服务不支持流式时，在设置取消“流式回复”。支持多轮问答、Markdown、复制消息、新对话和停止回复。

右侧面板在 SQL / Shell / Note 间共享，切换工作区及隐藏面板保留当前对话和未发送内容。新对话清空当前聊天。改变地址或模型会重置后续请求的上下文，保留可见消息和未发送内容；只保存相同设置不会清空上下文。

## 数据与生命周期

- 只发送聊天输入及当前成功的问答历史，没有数据库结果、终端输出、笔记、附件、工具调用或自动执行。
- 聊天仅在本次应用运行中保留；配置使用现有 AES-GCM 本机 Vault，SQLite 仅存密文引用，不写明文 Key，不访问系统钥匙串。
- 取消或失败保留已收到的文字，不加入后续上下文。问题自动放回空输入框供重试，不覆盖等待期间新写的内容。
- HTTP 不跟随重定向，不显示远端错误响应内容；HTTPS 校验证书，HTTP 仅支持 localhost、回环或私有 IP。
- 单个问题 8 KiB、单个回复 32 KiB、请求上下文 64 KiB；按完整旧问答轮次裁剪。可见聊天至多 40 条且合计约 128 KiB，失败请求也纳入显示上限。
- 远端协议累计 2 MiB、流式单事件 128 KiB；总请求超时 3 分钟，建连 10 秒、响应头 45 秒。UI 更新合并并限制频率。
- 请求由现有任务管理器登记、取消和等待；新对话用代次忽略迟到回调。退出取消并等待网络工作；若草稿或笔记保存失败导致退出中止，重新读取已保存的 AI 配置，恢复可用状态。
